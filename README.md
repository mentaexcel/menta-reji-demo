# メンタレジ ── 自動化の練習用ダミーWebシステム

**API を持たない「昔ながらの社内Webシステム」を再現した、練習用のダミーサイトです。**

RPA（Power Automate Desktop など）やブラウザ自動化・AIエージェントの練習台として、
遠慮なく操作・スクレイピング・自動化してもらうために作りました。

実在の企業・店舗・人物とは一切関係ありません。実データは含みません。

## デモ

👉 **https://mentaexcel.github.io/menta-reji-demo/**

`index.html` をブラウザにドラッグ＆ドロップするだけでも動きます（サーバー不要・通信なし）。

## このシステムの一番の特徴：支店ごとにログインが分かれています

架空のカフェチェーン5支店のPOS（レジ）売上管理システムです。

- **支店ごとにログインIDとパスワードが違います**
- ログインすると、**その支店のデータだけ**が表示されます
- **全社合計を見る画面はありません。本部一括のIDもありません**
- 他支店の伝票番号を直接URLに入れても、エラーになって見られません

つまり **5支店分の数字を集めるには、5回ログインし直すしかありません。**
これがこのシステムを練習台として作った理由です。

## データについて

- 期間：2026年8月1日〜8月31日（5支店合計で伝票 約6,000枚）
- 支店：北海道・東京・大阪・神奈川・沖縄（すべて架空）
- 商品14品目、支払方法4種、レジ担当者は支店ごとに4名（すべて架空）
- **`assets/data.js` の固定シードでその場生成**しています。データベースも通信もありません。
  何度開いても、誰が開いても、同じ数字が出ます。

## わざと残してある「自動化したくなるポイント」

練習台として役に立つように、古い業務システムにありがちな不便さを意図的に残しています。

1. **支店ごとにログインが分かれている** ── 全社の数字を出すには5回ログインし直すループが必要
2. **全社合計の画面が無い** ── 横断で見る手段がそもそも用意されていない
3. **CSV出力ができない** ── 画面から数字を取るしかない
4. **グラフが1つもない** ── 集計は自分で外に出す必要がある
5. **ページ送りが何十ページも続く** ── 全件取得はループ必須
6. **列のソートができない** ── 見出しをクリックしても反応しない
7. **日付が手入力** ── カレンダーが出ない
8. **画面幅が固定（950px）** ── スマホで見られない
9. **前月比・前年比が出ない**
10. **APIが無い** ── これがこのシステムの本質。裏口が無いので画面を操作するしかない

## 想定している使い方

- Power Automate Desktop / RPA の練習
  （Excelの一覧からIDとパスワードを1行ずつ読む → ログイン → 数字を取る → 書き戻す → ログアウト → 次の支店）
- ブラウザ自動化（Playwright・Selenium）の練習台
- AIエージェントにWeb操作をさせる実験
- 「APIがあるシステム」と「無いシステム」で自動化の作り方がどう変わるかの比較

ログイン状態は `sessionStorage` に保持しています。タブを閉じるかログアウトすると解除されます。

# メンタレジ ── 自動化の練習用ダミーWebシステム

**API を持たない「昔ながらの社内Webシステム」を再現した、練習用のダミーサイトです。**

RPA（Power Automate Desktop など）やブラウザ自動化・AIエージェントの
練習台として、遠慮なく操作・スクレイピング・自動化してもらうために作りました。

実在の企業・店舗・人物とは一切関係ありません。実データは含みません。

## デモ

👉 **https://mentaexcel.github.io/menta-reji-demo/**

`index.html` をブラウザにドラッグ＆ドロップするだけでも動きます（サーバー不要・通信なし）。

## 何のシステムか

架空のカフェ3店舗のPOS（レジ）売上管理システムです。

| 画面 | 内容 |
|---|---|
| index.html | トップ：お知らせ、本日の店舗別速報、直近5日の売上 |
| sales.html | 売上明細：レジ伝票 約3,500件・検索・50件ずつのページ送り |
| detail.html | 伝票詳細：1伝票の中身（レシート相当）。`?id=伝票番号` で開く |
| daily.html | 日別集計：日別売上と支払方法別の内訳 |
| items.html | 商品別売上：商品ランキングと構成比 |
| staff.html | スタッフ別：担当者別の売上・客単価 |

## データについて

- 期間：2026年8月1日〜8月31日（伝票 約3,500枚）
- 店舗：那覇本店 / 北谷店 / 名護店（すべて架空）
- 商品14品目、支払方法4種、担当者5名（すべて架空の名前です）
- **`assets/data.js` の固定シードでその場生成**しています。データベースも通信もありません。
  何度開いても、誰が開いても、同じ数字が出ます。

## わざと残してある「自動化したくなるポイント」

練習台として役に立つように、古い業務システムにありがちな不便さを意図的に残しています。

1. **CSV出力ができない** ── 画面から数字を取るしかない
2. **グラフが1つもない** ── 集計は自分で外に出す必要がある
3. **ページ送りが71ページ** ── 3,548件を50件ずつ。全件取得はループ必須
4. **列のソートができない** ── 見出しをクリックしても反応しない
5. **日付が手入力** ── カレンダーが出ない
6. **画面幅が固定（950px）** ── スマホで見られない
7. **前月比・前年比が出ない**
8. **APIが無い** ── これがこのシステムの本質。裏口が無いので画面を操作するしかない

## 想定している使い方

- Power Automate Desktop / RPA の練習（全ページを巡回して売上を集計する、など）
- ブラウザ自動化（Playwright・Selenium）の練習台
- AIエージェントにWeb操作をさせる実験
- 「APIがあるシステム」と「無いシステム」で自動化の作り方がどう変わるかの比較

## ファイル構成

```
.
├ index.html / sales.html / detail.html / daily.html / items.html / staff.html
└ assets/
   ├ style.css  … 見た目
   ├ data.js    … ダミーデータ生成（固定シード）
   └ app.js     … 共通ヘッダー・検索・整形処理
```
